05   AI/ML Pipeline

🎯
Competency Mapping Engine
Input: User profile + assessment responses + course history
Model: Multi-label classifier (4 domains × N skills)
Output: Competency vector [statistical: 0.7, technical: 0.4, ...]
Training: Labeled competency data from NSSTA
🔍
Semantic Search Engine
Embeddings: Sentence-BERT / OpenAI Embeddings
Vector DB: pgvector / Pinecone
Query: "Learn Python for data analysis" → ranked courses
Features: Synonym matching, context-aware ranking
📝
Question Generation (LLM)
Input: Uploaded document / video transcript
Model: Fine-tuned LLM or GPT-4 API
Output: MCQs + quizzes with explanations
Features: Difficulty levels, topic tagging, instant evaluation
📈
Adaptive Assessment
Algorithm: Item Response Theory (IRT)
Model: Bayesian Knowledge Tracing
Behavior: Adjusts difficulty based on responses
Output: Precise skill level estimation + confidence

08   Security & Compliance

RequirementImplementation
RBACAdmin, Manager, Learner, Trainer roles
SSOSAML 2.0 / OAuth 2.0 (Keycloak)
EncryptionAES-256 at rest, TLS 1.3 in transit
Government CloudNIC / MeitY empaneled cloud
Secure APIsJWT tokens, rate limiting, validation
ComplianceIT Act 2000, DPDP Act 2023
Audit LoggingAll access logged with timestamps

Security Principles

🔒 Least Privilege
Users only access what their role requires
🛡️ Data Minimization
Collect only what's necessary, delete when no longer needed
🔑 API Key Protection
Keys in environment variables, never in source code
📝 Audit Trail
Every action tracked, timestamped, and reviewable
